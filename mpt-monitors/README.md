Folders:

 - `bin/` will contain the compiled binaries
 - `src/` contains the sources of MPT monitors (without input definitions)
 - `inputs/` contains the input definitions for monitors
 - `tests/` contain tests for MPT monitors (not relevant for the experiments)

 - `rvhyper/` contains scripts and components to run experiments with RVHyper
              (it was not a part of the RV'23 submission)
